# Gamer Hub

Особистий веб-сайт-портфоліо, присвячений колекції улюблених комп'ютерних ігор, стратегій та пісочниць (Minecraft, Factorio, Subnautica, Hearts of Iron IV тощо).

##  Про проєкт
Цей проєкт створений як практична робота. Сайт містить інформацію про ігри, у які я граю, збірки з модами, інформацію про стріми та посилання на соціальні мережі.

##  Технології
Проєкт розроблено з використанням сучасних веб-технологій:
**HTML5** — структурована розмітка сторінки.
**CSS3 (Flexbox & CSS Grid)** — адаптивний дизайн та сучасне стилізування.
**Google Fonts** — зручні шрифти та візуальне оформлення.
